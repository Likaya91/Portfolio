## Видео на обложке MAESTRO

1. Подготовьте вертикальный MP4 с кодеком H.264. Пропорции блока в макете близки к 1:2. Видеоплеер показывает весь кадр.
2. Загрузите файл в GitHub в папку `assets/maestro/` под именем `maestro.mp4`.
3. Откройте `maestro.html` в GitHub, нажмите ✎ и замените `data-video-src=""` на `data-video-src="assets/maestro/maestro.mp4"`. Сохраните изменение через **Commit changes**.
4. После завершения **Deploy portfolio to GitHub Pages** откройте страницу MAESTRO. Ролик запускается без звука и повторяется. Нажмите на обложку, чтобы поставить его на паузу или возобновить. При включённом уменьшении движения видео запускается по нажатию.

До подключения видео в том же месте показан кадр из макета.
